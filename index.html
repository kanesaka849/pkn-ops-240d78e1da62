記事作成ワークフロー（完全版 SOP）
🔄 新記事を作るときの手順（20ステップ）
Phase 1: 企画（テーマ決め〜タイトル確定）
  1. テーマ候補を決める — 下の「バズるネタ帳」から選ぶ
  2. キーワード調査 — ラッコキーワード/Ubersuggest/Googleトレンドで検索ボリューム確認
  3. タイトル決定 — 結論＋数字＋検索キーワード32文字以内、「AIが○○本読んだ」フォーマット
  4. コンプライアンス事前チェック — テーマに薬機法・景表法リスクがないか確認（健康/ダイエット系は特に注意）
Phase 2: 記事制作（note記事・LP等）
  1. note記事執筆 — PREP法・黄金構成5ステップ、AI目線で統一。Pの字のボケ挿入
  2. 有料ライン設定（有料記事の場合） — 無料部分30-50%。「続きが知りたい」ピークで切る
  3. 記事の画像作成 — 見出し画像・図解+マスコット。場面ベースで配置（見出し直後/データ/比較等）。Pillow/OpenAI API
  4. アイキャッチ画像作成 — 7原則準拠（高コントラスト・3語・数字・補色等）。子豚のスコアP配置
  5. note plaintext版作成 — 【見出し】【太字】【区切り線】【画像】マーカー付き
  6. LP（GitHub Pages）作成 — 白基調デザイン。OGP/JSON-LD/FAQ Schema設定
Phase 3: 展開コンテンツ作成（動画・カルーセル・Xスレッド等）
  1. TikTok動画JSON作成（3-5本） — フック型スライド、私語枚、1-34秒。記事別アクセントカラー
  2. 動画生成 — python generate_video.py slides.json（BGMなし。TikTok/IGはアプリで後付け）
  3. YouTube Shorts用動画生成 — python generate_video.py slides.json --bgm bgm.mp3（BGM焼き付け）
  4. Instagramカルーセル作成（3本） — CTA最終スライド必須、@pokano_ai含む
  5. Instagramストーリー作成（3本）
  6. Xスレッド作成（3本+単発ツイート） — ハッシュタグ3-5個、@pokano_ai含む
Phase 4: 成果物チェック（公開前）
  1. check_all.py実行 — 全25カテゴリ、FAIL=0になるまで修正
  2. 目視チェック — タイトルに数字・32文字以内 / 冒頭50文字でフック / PREP構成 / 動画フック≠タイトル繰り返し
  3. pokano_config.json更新 — 新記事のタイトル・URL・価格・ファイルパスを追加
Phase 5: 公開と拡散
  1. 公開 — note投稿 → GitHub Pagesプッシュ → 公式サイト更新 → ダッシュボード更新
  2. 拡散 — X引用リポスト（19-21時） → TikTok投稿（トレンド音源追加） → IG Reels → YouTube Shorts
  3. Xセルフリプライ — 投稿後30分以内に補足情報をツリーで追加（リプライ=いいねの30-75倍のスコア）
